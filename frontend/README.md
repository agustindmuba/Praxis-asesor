# frontend

Aplicación web del Praxis Asesor. Next.js 14 (App Router) + TypeScript strict + Tailwind + shadcn/ui.

## Estructura prevista

```
frontend/
├── app/           # rutas (App Router)
├── components/    # componentes UI compartidos
├── lib/           # utilidades, clientes API, hooks
└── package.json
```

Detalles de elección de stack y convenciones en [`../ARCHITECTURE.md`](../ARCHITECTURE.md) y [`../CLAUDE.md`](../CLAUDE.md).
