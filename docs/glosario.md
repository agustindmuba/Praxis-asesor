# Glosario parlamentario — Praxis Asesor

> Versión extendida del glosario incluido en [`../CLAUDE.md`](../CLAUDE.md) (§6). Mantener sincronizado.

Este glosario es referencia obligatoria para nombrar entidades, validar parsers y comunicarse con usuarios. Los términos tienen sentido jurídico/reglamentario específico; usarlos con precisión.
