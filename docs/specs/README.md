# Specs de features

Cada feature del MVP (ver [`../../PRODUCT.md`](../../PRODUCT.md) → "Features en orden de implementación") tiene una spec acá antes de empezar a codear.

## Formato

Archivo: `NN-titulo-feature.md` (NN = número de la feature en PRODUCT.md).

Estructura mínima:

```markdown
# NN — Título de la feature

- **Estado**: borrador | aprobada | en desarrollo | entregada
- **Bloque del MVP**: 1/2/3/4

## Problema

Para qué usuario, qué dolor.

## Solución propuesta

Qué hace el sistema (no cómo se implementa).

## Criterios de aceptación

Checklist verificable.

## Fuera de alcance

Qué quedó afuera y por qué.

## Notas técnicas

Apuntes que el dev necesita: endpoints externos, parsers involucrados, integraciones, etc.
```
